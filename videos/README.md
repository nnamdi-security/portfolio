# Video cards

Drop the exported HeyGen `.mp4` files here, named to match what `index.html`
already expects:

- `daily-dozen-video-card.mp4`
- `podcast-video-card.mp4`
- `blog-video-card.mp4`
- `sentiment-analysis-video-card.mp4`

Each should be 60 seconds or under (per the assignment brief). Once a file
is in place, replace its matching `PLACEHOLDER-*.jpg` poster in
`images/project-images/` with a real still frame from the video, and swap
out the disabled "Watch on YouTube" link in that card if you've also
uploaded it to YouTube.
