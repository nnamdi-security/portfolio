Enterprise Security Simulation Lab

Built a full offense/defense/monitoring environment in Docker on Kali Linux: a vulnerable target app (DVWA) and honeypot behind a ModSecurity WAF with the OWASP Core Rule Set, plus an ELK stack for monitoring. Ran real attacks (Nmap recon, Metasploit brute-force, manual SQL injection and XSS), confirmed the WAF blocked them with HTTP 403, and visualized 136 indexed security events across a 4-panel Kibana dashboard.

PrestaShop Security Assessment: Complete Guide

A measured before/after hardening project on PrestaShop 8.1 — tested all 10 OWASP Top 10 categories using Burp Suite, OWASP ZAP, SQLMap, and Nikto. Result: an 89% overall attack-blocking rate (25 of 28 simulated attacks), critical vulnerabilities cut from 8 to 0, and high-risk vulnerabilities cut from 12 to 1.
